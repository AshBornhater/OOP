# OOP

This repository contains my assignments for the Object-Oriented Programming (OOP) course, written in Java. Each assignment lives in its own folder and covers one topic from the course material.

## Contents

| Folder | Topic |
| --- | --- |
| `Array&ArrayList` | Working with arrays and the `ArrayList` collection |
| `Inheritance&Polymorphism` | Class hierarchies, abstract classes, method overriding, and polymorphism |

Each folder has its own `README.md` with a more detailed explanation of the code.

## Requirements

- Java Development Kit (JDK) 8 or newer

## Running an Assignment

```bash
cd Inheritance&Polymorphism
javac *.java
java Main
```

## About

This repository is for coursework only and will grow as new topics are covered in class.
